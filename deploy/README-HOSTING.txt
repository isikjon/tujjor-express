TUJJOR EXPRESS CHIRCHIQ — СТАТИЧЕСКАЯ СБОРКА ДЛЯ ОБЫЧНОГО PHP-ХОСТИНГА
=====================================================================

Что это
-------
Готовый сайт (HTML / JS / CSS / 3D-ассеты), собранный из Next.js в статический экспорт.
Node.js на сервере НЕ нужен. Нужен обычный Apache/LiteSpeed-хостинг с .htaccess (mod_rewrite)
и PHP 7.4+ (PHP используется только одним файлом — api/track.php, эндпоинт отслеживания).

Как загрузить
-------------
1. Распакуйте архив и загрузите ВСЁ его содержимое в корень сайта
   (обычно public_html, www или htdocs). Файл index.html должен оказаться прямо в корне.
2. Убедитесь, что загрузился скрытый файл .htaccess (в файловом менеджере cPanel включите
   «Показывать скрытые файлы»; при загрузке через FTP — включите показ скрытых файлов).
   Также есть .htaccess в папках geo/ и api/data/.
3. Откройте сайт по домену. Проверьте:
   - главная страница (3D-сцена с коробкой, скролл — путь Китай → Чирчик)
   - /services, /business, /tracking, /contacts — открываются без .html
   - /api/track/TEST-1234 — отвечает JSON {"found":false,"code":"TEST-1234"}
   - /nesushestvuet — красивая 404
4. Сайт рассчитан на установку в КОРЕНЬ домена (не в подпапку вида site.uz/tujjor/).
   Для подпапки нужна пересборка с basePath — скажите, соберу.

Домен
-----
В sitemap.xml, robots.txt, canonical и Open Graph зашит адрес https://tujjor-express.uz
(значение NEXT_PUBLIC_SITE_URL на момент сборки). Если реальный домен другой — сообщите,
пересоберу с правильным адресом (иначе соцсети/поисковики будут ссылаться не туда).

HTTPS
-----
Рекомендуется включить SSL на хостинге (Let's Encrypt обычно есть бесплатно). Чтобы
принудительно перенаправлять на https, раскомментируйте блок «Force HTTPS» в .htaccess.

Отслеживание (tracking)
-----------------------
Пока склад не подключён, любой трек-номер отвечает «не найден», и сайт ведёт клиента в Telegram.
Чтобы вручную выдавать статусы, создайте файл api/data/tracking.json по образцу
api/data/tracking.example.json (ключ — трек-номер, статусы: received, warehouse, consolidated,
transit, uzbekistan, chirchiq, ready). Папка api/data/ закрыта от прямого доступа.
Когда появится реальная система (1С / бот / CRM), заменяется только api/track.php.

Если что-то не так
------------------
- «500 Internal Server Error» сразу после загрузки — хостинг не принял какую-то директиву
  .htaccess. Все необязательные блоки уже обёрнуты в <IfModule>; напишите мне текст ошибки
  из логов хостинга (error_log) — поправлю.
- Страницы /services и т.п. дают 404 — не загрузился .htaccess или отключён mod_rewrite.
- /api/track/... отдаёт исходник PHP или 404 — на аккаунте не включён PHP.

Обновление
----------
Новая версия сайта = снова распаковать архив в корень поверх старых файлов. Папка api/data/
с вашим tracking.json при этом не перезаписывается (в архиве только пример).
